# Installing the OrderEazi Commerce Headless API SDK from S3

The OrderEazi Commerce TypeScript SDK is automatically generated and hosted on AWS S3 for each release version. This guide explains how to install and use it in your React frontend or other TypeScript/JavaScript projects.

## SDK Hosting

The SDK is hosted on AWS S3 and served via CloudFront at:
- **S3 Bucket**: `s3://za.co.storefront7.resources`
- **CloudFront URL**: `https://content.storefront7.co.za`
- **Path Structure**: `/{VERSION}/sdk/`

For example, version `1.0.0` would be available at:
- `https://content.storefront7.co.za/1.0.0/sdk/ordereazi-commerce-sdk-1.0.0.tgz`

## Installation Methods

### Method 1: Install from CloudFront URL (Recommended)

Install the SDK directly from the CloudFront URL:

```bash
npm install https://content.storefront7.co.za/{VERSION}/sdk/ordereazi-commerce-sdk-{VERSION}.tgz
```

**Example:**
```bash
npm install https://content.storefront7.co.za/1.0.0/sdk/ordereazi-commerce-sdk-1.0.0.tgz
```

### Method 2: Install Latest Version for a Release

Each version also includes a `latest` tarball for convenience:

```bash
npm install https://content.storefront7.co.za/{VERSION}/sdk/ordereazi-commerce-sdk-latest.tgz
```

**Example:**
```bash
npm install https://content.storefront7.co.za/1.0.0/sdk/ordereazi-commerce-sdk-latest.tgz
```

### Method 3: Using package.json

Add the SDK to your `package.json` dependencies:

```json
{
  "dependencies": {
    "@ordereazi/commerce-sdk": "https://content.storefront7.co.za/1.0.0/sdk/ordereazi-commerce-sdk-1.0.0.tgz"
  }
}
```

Then run:
```bash
npm install
```

### Method 4: Using a Custom npm Registry (Advanced)

If you prefer to use npm's standard installation syntax, you can set up a custom registry or use a `.npmrc` file, but the direct URL method is simpler and recommended.

## Finding the Correct Version

### Check Available Versions

You can check what versions are available by:

1. **Check the S3 bucket directly** (if you have access):
   ```bash
   aws s3 ls s3://za.co.storefront7.resources/ --recursive | grep sdk
   ```

2. **Check the install.json file** for each version:
   ```bash
   curl https://content.storefront7.co.za/{VERSION}/sdk/install.json
   ```

3. **Contact your DevOps team** for the current production version

### Version Format

The SDK version matches the Storefront release version:
- Storefront version: `1.0.0` → SDK version: `1.0.0`
- Storefront version: `1.2.3` → SDK version: `1.2.3`

## Usage

After installation, import and use the SDK in your code:

The SDK is generated by openapi-generator's `typescript-axios` template, which produces a shared
`Configuration` object plus one `XxxApi` class per resource (named from the API's OpenAPI tags) - not a single
hand-wrapped client. Exact class names depend on what's in the spec at generation time; this shape is
representative:

```typescript
import { Configuration, CartApi, CheckoutApi } from '@ordereazi/commerce-sdk';

const config = new Configuration({
  basePath: 'https://api.storefront7.co.za',
  // Store Access Key (pk_store_.../sk_store_...) and/or JWT bearer token, per endpoint
  baseOptions: { headers: { 'X-Commerce-Key': 'pk_store_...' } }
});

const cartApi = new CartApi(config);
const cart = await cartApi.cartGetCartApi();

const checkoutApi = new CheckoutApi(config);
const paymentOptions = await checkoutApi.checkoutGetPaymentOptionsApi();
```

## Updating the SDK

To update to a new version:

1. **Uninstall the old version:**
   ```bash
   npm uninstall @ordereazi/commerce-sdk
   ```

2. **Install the new version:**
   ```bash
   npm install https://content.storefront7.co.za/{NEW_VERSION}/sdk/ordereazi-commerce-sdk-{NEW_VERSION}.tgz
   ```

3. **Update your code** if there are any breaking changes (check release notes)

## Troubleshooting

### Installation Fails with 404

- Verify the version exists: `curl https://content.storefront7.co.za/{VERSION}/sdk/install.json`
- Check that the version number is correct (no typos)
- Ensure the SDK was built and deployed for that version

### Type Errors After Installation

- Make sure you're using TypeScript 5.0 or higher
- Clear `node_modules` and reinstall: `rm -rf node_modules package-lock.json && npm install`
- Check that the SDK version matches your API version

### Network/CORS Issues

- The SDK is served via CloudFront with public-read access
- If you're behind a corporate firewall, ensure CloudFront URLs are whitelisted
- Check that your network allows HTTPS connections to `content.storefront7.co.za`

## CI/CD Integration

### GitHub Actions / GitLab CI

```yaml
- name: Install OrderEazi Commerce SDK
  run: |
    npm install https://content.storefront7.co.za/${{ env.STOREFRONT_VERSION }}/sdk/ordereazi-commerce-sdk-${{ env.STOREFRONT_VERSION }}.tgz
```

### Environment Variables

Set the version as an environment variable:

```bash
export STOREFRONT_VERSION=1.0.0
npm install https://content.storefront7.co.za/$STOREFRONT_VERSION/sdk/ordereazi-commerce-sdk-$STOREFRONT_VERSION.tgz
```

## Local Development

For local development, you can link to the SDK source:

```bash
cd src/Tools/Storefront.Sdk/TypeScript
npm link

cd ../../../react-storefront
npm link @ordereazi/commerce-sdk
```

Or use the local path directly in `package.json`:

```json
{
  "dependencies": {
    "@ordereazi/commerce-sdk": "file:../src/Tools/Storefront.Sdk/TypeScript"
  }
}
```
